# Methodology — stock-insights-1.0

## Data contract

Use up to five years of daily Yahoo Finance observations fetched with `auto_adjust=False`, retaining adjusted close for returns and unadjusted close for quantity valuation. Adjusted closes reflect the provider's corporate-action adjustments; they are not independently audited exchange data. Preserve supplied split events for quality checks. No interpolation, backward filling or imputed zero returns. Drop duplicate dates keeping the last provider record and expose that count. Mark invalid/nonpositive prices missing. Flag extreme adjusted returns for caution rather than silently discarding possible real events.

Restrict bars to sessions closed at least 15 minutes before analysis time, using NSE, BSE or NYSE exchange calendars. NYSE provides the US equity session schedule, including early closes. NIFTY 50 uses the Indian schedule. Unsupported foreign-exchange listings are rejected. Expected but absent bars remain missing, invalidating dependent daily returns and historical windows. When the latest expected session is missing, analytics fall back to observed data with a visible delay warning. Movement trims to the latest session with valid one-session stock and benchmark returns; if the benchmark is unavailable, only stock/volume context is shown. Portfolio Fit uses its latest common valid return and valuation date across the candidate and all included holdings. Responses retain the expected exchange session and identify the actual analysis date. Missing sessions inside the history remain gaps; they are never filled or bridged. This fallback affects data availability, not the calculation formulas or recorded study results.

Return `r[t] = adjusted_close[t] / adjusted_close[t-1] - 1`. Perform the operation before dropping missing values or aligning instruments. Portfolio prices are valued at the latest common date, never at inconsistent timestamps. Same-currency holdings are aggregated by symbol, with foreign-currency holdings listed as excluded. Unknown sector classification is explicitly shown; current company sector classifications are not reconstructed historically.

## Portfolio Fit

Let current close-value weights be `w`, holdings values `v`, candidate index `j`, and new money `a`. After-purchase weights are `(v + a*unit_j) / (sum(v)+a)`. This assumes fractional shares, no selling, fees or taxes. Stock concentration is the largest weight and HHI `sum(w²)`; sector exposures sum classified stock weights.

Require 120 common one-session returns in the latest uninterrupted common history. Earlier gaps and listing dates shorten this period so compounded portfolio wealth never jumps over missing returns. Fit Ledoit–Wolf covariance to this common return period. Annualized volatility is `sqrt(252*wᵀΣw)`. The sample-covariance counterpart is retained for evaluation, not presented as a second recommendation. Candidate correlation uses historical Pearson correlation with the existing fixed-weight portfolio. Largest weighted overlap ranks positive correlation multiplied by existing holding weight. It is an exposure indicator, not causal attribution.

Daily downside is the fifth percentile of weighted daily returns. Historical drawdown is calculated from compounded weighted returns, with starting wealth 1. These describe a hypothetical DAILY-REBALANCED portfolio maintaining the displayed weights, not the user's actual transaction history or a buy-and-hold reconstruction. Data alignment can shorten the history; show its count and bounds. Historical covariance cannot guarantee future diversification or risk reduction.

## Unusual Movement

For each assessed session, fit OLS `stock_return = intercept + beta*market_return` using the previous 120 valid aligned daily returns. The out-of-sample residual is actual return minus the regression estimate. Compare the final residual with the previous 60 residuals, each generated using its own preceding 120 observations. At least 181 aligned returns are needed. The median-based standardized score is `(residual - median(reference)) / (1.4826 * MAD(reference))`. Flag `abs(score) > 3.5`. This is a heuristic screening threshold, not a formal outlier hypothesis test or a Gaussian-tail probability. A zero/negligible MAD withholds standardization; never replace it with invented confidence.

Volume multiple is latest volume / median of the preceding 20 scheduled-session volumes, available only when all 20 exist and their median is positive. Stock-only robust scores use the preceding 60 available returns and serve as the academic baseline. News from the stock provider must have a valid URL and a timestamp within the previous seven days; future-dated and undated records are withheld. Provider association does not independently verify company relevance. Headlines are contextual links, never causality labels. Historical-demo mode displays no current headlines.

## Historical Experience

Periods 1/3/6/12 months mean 21/63/126/252 trading sessions. Return is ending adjusted close / starting adjusted close - 1; every expected close in the window must exist. Require 30 complete windows. Compute median, 10th/90th percentiles, losing-window fraction and minimum return. Ending value is entered amount × (1+return). The distribution counts actual windows; overlaps mean dependence, not independent trials or future outcome probabilities.

Maximum drawdown is `min(price / running_max(price) - 1)` over observed adjusted prices. Report peak, trough and first subsequent recovery to the peak; otherwise report not recovered. Recovery counts observed sessions when gaps exist. A zero drawdown has immediate recovery. These are full-history drawdowns, not necessarily the selected holding-period worst return.

## Evaluation protocol

Fixed universe: TCS, Infosys, SBI, Apple, Microsoft and Nvidia. Price periods follow the five-year retrieval window; no performance-based date selection. Compare covariance estimators using each market's common return dates. Use the last chronological 20% for evaluation, expanding preceding training history, 21-session nonoverlapping evaluation origins, and the following 21-session sample volatility as the reference. Evaluate fixed before weights `[.5,.5,0]` and after weights `[1/3,1/3,1/3]` for the listed symbol order. These are illustrative portfolios, not real user holdings. Report mean absolute error of annualized volatility separately by market and portfolio.

On each market's chronological evaluation period, assess every 21st eligible date for each stock. Evaluate observed final returns, a controlled -8-percentage-point market-return shock with the stock changed by its preceding estimated beta, a +8-percentage-point stock-specific return shock, and a missing stock price. Only the final input is changed; preceding reference history stays untouched. These stress checks demonstrate sensitivity and availability behavior. They are NOT labeled historical anomaly accuracy. The broad-market shock mechanically follows the fitted market model, which favors a residual-based detector; disclose this construction. Normal observed alert rates cannot establish a false-positive rate without independently annotated truth.

Numerical reference tests verify rolling outcomes, corporate-action handling, gaps, covariance invariants, drawdowns and recovery. Historical examples are inspected separately without inferred news causes. No significance, future profitability, general superiority or user-understanding improvement claim is supported by this small study. Configurations, versions, price-file hashes and every evaluation row are saved for reproduction.
